Project

Aksharamala

A convolutional neural net and web app that teaches Malayalam script.

PythonPyTorchpandasCompletedDemo

Overview

Learning a script by writing it.

Malayalam has 56 letters and a lot of visually similar shapes, which makes flashcards a poor way in — recognising a character is not the same skill as producing one. Aksharamala flips that: you draw the letter, and a convolutional classifier tells you what you actually wrote rather than what you meant to write.

How it works

Model and app.

  • Data
    Handwritten Malayalam character images, normalised to a fixed canvas size and augmented with small rotations, shifts, and stroke-thickness variation so the model tolerates real handwriting.
  • Model
    A convolutional network in PyTorch — stacked conv/pool blocks into a dense classifier over the character set, trained with cross-entropy.
  • App
    A browser canvas captures the stroke, sends it to the model, and returns the predicted character with its confidence, so a wrong guess doubles as feedback on the stroke itself.
